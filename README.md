# EasyFarm — AI Bot Suite for wow Forever

Веб-приложение и интерактивный комплекс для разработки, конфигурации и тестирования бота для MMORPG **Throne and Liberty**.

## Возможности комплекса

1. **Редактор порядка ротации скиллов (Rotation Configurator)**:
   - Интерактивная 4x3 сетка слотов (1..9, 0, -, =) с визуализацией приоритетов каста.
   - Отрисовка цепочки стрелок и возвратной дуги цикла.
   - Редактирование комбинаций кнопок геймпада (Xbox 360: RB, RT, X, Y, A, B, DPAD), кулдаунов и названий скиллов.
   - Экспорт и импорт в формат `skills_config.json`.
   - Готовые пресеты тактик (Бурст-урон, AoE фарм, стандартная ротация).

2. **Симулятор бота и конечного автомата (FSM Simulator)**:
   - Полная эмуляция цикла состояний `SEARCH` ↔ `COMBAT` на 60 FPS.
   - Интерактивный видовой экран с мобами, полоской здоровья и рамкой захвата ROI.
   - Расчет смещения от центра и зоны нечувствительности (мертвая зона 18px).
   - Плавный доворот камеры правым стиком (Smoothstep кривая Безье).
   - Интерактивный HUD геймпада Xbox 360 с подсветкой нажимаемых клавиш.
   - Горячие клавиши F4 (старт/паника) и F5 (диагностический тест комбо ротации).
   - Консоль логов в реальном времени с таймкодами (формат `logs/combo_test_*.txt`).

3. **Калибровка машинного зрения (Vision & HSV Sandbox)**:
   - Настройка нижних и верхних порогов HSV для красных и желтых HP-баров (OpenCV `cv2.inRange`).
   - Слайдеры для оффсетов ROI (сдвиг от центра экрана, ширина, высота).
   - Симуляция бинарной маски детекции пикселей.
   - Экспорт Python-кода конфигурации в `src/config/vision_config.py`.

4. **Дорожная карта (Roadmap Tracker)**:
   - Отслеживание этапов разработки 1-6 (Инфраструктура, Зрение, Движения, FSM, Социальный модуль, Тестирование).
   - Интерактивные чекбоксы с сохранением прогресса в localStorage.
   - Пояснения к каждой задаче («Как это выглядит на практике»).

5. **Архитектурная документация & Античит (Docs)**:
   - Стандарты защиты от Easy Anti-Cheat (EAC).
   - Обоснование перехода с Interception на ViGEmBus.
   - Неблокирующие таймеры и humanizer задержек.

## Запуск в среде AI Studio

```bash
npm run dev
```

Приложение запускается на порту `3000` (host `0.0.0.0`).
