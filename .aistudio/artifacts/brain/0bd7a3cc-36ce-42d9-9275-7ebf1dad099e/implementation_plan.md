# Плавное 60 FPS удаление маршрута и анимация высоты списка

План переработки эффекта удаления маршрута: замена ресурсоёмких фильтров размытия на GPU-ускоренные трансформации (60 FPS без лагов) и внедрение двухфазного плавного схлопывания высоты контейнера без скачков интерфейса.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> **Причина текущих «2 FPS»**: одновременная анимация CSS `filter: blur()`, `box-shadow` и некомпозитных свойств верстки (`max-height`, `margin`, `padding`) вызывает перерасчет геометрии (layout reflow) и программную растеризацию на каждом кадре в окне pywebview.
> 
> **Решение**: перенос анимации на чистые GPU-композитные свойства (`transform: translate3d, rotateY, scaleX` + `opacity`) и применение техники плавного двухфазного схлопывания высоты через CSS Grid / переход контейнера.

- **Подтверждённое решение 1**: Удаление происходит мгновенно по клику на иконку корзины без блокирующих диалогов подтверждения.
- **Подтверждённое решение 2**: Эффект исчезновения влево со скручиванием в вертикальный столбик сохраняется, но строится на аппаратном 3D-ускорении (`perspective`, `rotateY`, `scaleX`, `translate3d`) с аппаратной плавностью 60 кадров/с.
- **Подтверждённое решение 3**: Плавное изменение размера списка — оставшиеся карточки мягко подтягиваются вверх без резких скачков.

---

### 1. Overview & Core Concept

- **Что делает**: Пользователь нажимает на иконку удаления маршрута в списке. Карточка мгновенно, с тактильной физикой и плавностью 60 FPS, скручивается к левому краю и растворяется, а список ниже плавно и бесшовно скользит вверх, адаптируя высоту рабочей области без дерганий.
- **Контекст**: Компактное окно приложения (520×440 px), темная тема World of Warcraft, встроенный веб-движок pywebview.

---

### 2. User Experience & Visual Design

- **Пользовательский сценарий**:
  1. Пользователь нажимает на кнопку «Удалить» (корзина) у ненужного маршрута.
  2. **Фаза 1 (0 – 260 мс)**: Карточка с аппаратным ускорением (`will-change: transform, opacity`) поворачивается вокруг левой оси (`transform-origin: left center`), сжимается по оси X в изящную световую колонку и уходит влево с затуханием прозрачности.
  3. **Фаза 2 (160 – 420 мс)**: Слот карточки плавно уменьшает высоту от исходной до 0px через CSS Grid `grid-template-rows: 1fr` $\rightarrow$ `0fr` (или плавный transition высоты и отступов).
  4. Соседние элементы снизу мягко всплывают на освободившееся место.
  5. По завершении анимации маршрут удаляется из React-состояния, всплывает ненавязчивый тост об удалении.

- **Стилистика и тема**:
  - Сохранение фирменного тёмного стиля WoW (угольно-синий фон `#07090e`, акцентные оттенки циан `#06b6d4`, графитовые рамки).
  - Никаких кислотных лазерных полос или заторможенных эффектов.

---

### 3. Key Product Decisions & Trade-Offs

- **Решение 1: Замена `filter: blur(...)` на GPU-композитинг**:
  - *Выбранный подход*: Использование 3D-проекции `perspective(600px) rotateY(-80deg) scaleX(0.05) translate3d(-35px, 0, 0)` в сочетании с плавной кривой прозрачности `cubic-bezier(0.2, 0.9, 0.3, 1)`.
  - *Почему*: `filter: blur` на каждом кадре требует программного размытия всего растра, что в движках WebKit/pywebview моментально просаживает FPS до 2–5. GPU-трансформации выполняются на видеочипе с фиксированными 60 FPS.
  - *Альтернативы*: Оставить blur — приводит к постоянным лагам и фризам интерфейса.

- **Решение 2: Плавное схлопывание высоты слота (Collapsible Grid / Smooth Height)**:
  - *Выбранный подход*: Анимированный обёрточный контейнер со сглаженным переходом `grid-template-rows: 1fr -> 0fr` или `transition: max-height 0.3s cubic-bezier(0.4, 0, 0.2, 1), margin 0.3s, opacity 0.3s`.
  - *Почему*: Гарантирует, что нижние карточки не прыгают мгновенно на место удалённой, а плавно и органично занимают освободившееся пространство.

### 4. Technical Architecture & Data Strategy

#### Схема потока анимации и удаления

```
[Клик по корзине]
       │
       ▼
[handleDeleteRoute(route)] ──► API: api.delete_route(route.id) (в фоне)
       │
       ├─► [setDissolvingId(route.id)]
       │         │
       │         ▼
       │   ┌───────────────────────────────────────────────┐
       │   │  Фаза 1: GPU 3D Curl (0 - 260ms)              │
       │   │  transform: perspective rotateY scaleX        │
       │   │  opacity: 1 -> 0                              │
       │   └───────────────────────┬───────────────────────┘
       │                           │
       │                           ▼
       │   ┌───────────────────────────────────────────────┐
       │   │  Фаза 2: Container Height Collapse (160-420ms)│
       │   │  grid-template-rows: 1fr -> 0fr               │
       │   │  Нижние карточки плавно скользят вверх        │
       │   └───────────────────────┬───────────────────────┘
       │                           │
       │                           ▼
       └─► [440ms Timeout] ──► [setRoutes(filter out)] + [onToast]
```

#### Файлы для доработки:
1. `src/index.css`:
   - Оптимизированные GPU-keyframes `.route-curl-exit` с использованием `transform3d`, `rotateY`, `scaleX` и `opacity` (без `filter: blur`).
   - Класс плавного сжатия высоты контейнера `.route-item-wrapper`.
2. `src/components/RoutesView.tsx`:
   - Оборачивание каждой карточки маршрута в анимируемый контейнер строки.
   - Синхронизация времени завершения анимации и очистки состояния.
