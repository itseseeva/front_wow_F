# Implementation Plan - Полноценная светлая тема и пропорциональное масштабирование UI

Перевод интерфейса Stealth HUD на адаптивную систему с полноценной высококонтрастной светлой темой и пропорциональным масштабированием для любых мониторов (включая Full HD, 2K, 4K и ультраширокие экраны).

## User Review Required

> [!IMPORTANT]
> По результатам уточнения требований подтверждены:
> 1. **Полноценная светлая тема**: Чистый контрастный дизайн (светлый фон `#f4f4f5` / `#fafafa`, контрастный глубокий текст `#09090b` / `#18181b`, тонкие графитовые границы и инвертированный мягкий specular-блик), переключаемый через кнопку на верхнем тулбаре и сохраняемый в настройках.
> 2. **Пропорциональное масштабирование**: Интерфейс больше не привязан к фиксированным пикселям (`350px`, жесткие отступы). Контейнеры, типографика и сетка масштабируются пропорционально экрану (через адаптивный CSS viewport-scale и гибкую сетку Tailwind), заполняя экран сбалансированно без растягивания или пустот.

## Proposed Changes

### 1. Глобальная дизайн-система и темы (`src/index.css`)
#### [MODIFY] `src/index.css`
- Настроить поддержку Tailwind CSS v4 для темной и светлой темы:
  - `@custom-variant dark (&:where(.dark, .dark *));`
  - CSS-переменные для адаптивного скейлинга шрифтов и отступов через `clamp()` / CSS viewport scaling (`--scale-factor`).
  - Переменные для токенов интерфейса:
    - **Dark**: фон `#09090b`, текст `#f4f4f5`, приглушенный `#71717a`, hover-бордер `rgba(255, 255, 255, 0.1)`, specular `rgba(255, 255, 255, 0.18)`.
    - **Light**: фон `#f8fafc` / `#ffffff`, текст `#09090b`, приглушенный `#64748b`, hover-бордер `rgba(0, 0, 0, 0.12)`, specular `rgba(0, 0, 0, 0.1)`.

### 2. Главный макет и адаптивное масштабирование (`src/App.tsx`)
#### [MODIFY] `src/App.tsx`
- Синхронизировать класс `dark` на корневом элементе `document.documentElement` при смене `theme` ('dark' | 'light').
- Убрать жестко зафиксированные абсолютные координаты (`left: '350px'`) центральной рабочей области.
- Перевести главный каркас на адаптивный гибкий фреймворк:
  - Левый сайдбар: `w-72 lg:w-80 xl:w-96 2xl:w-[420px]` с плавной адаптацией.
  - Центральная зона: адаптивная ширина с правильным центрированием и выравниванием по сетке монитора.
  - Поддержка полноэкранного режима (`F11` / разворот окна): интерфейс органично увеличивает размер карточек и интервалы, сохраняя визуальную эстетику Ghost UI.
- Адаптировать фоны для светлой темы: контрастный чистый светлый фон без шума и артефактов.

### 3. Верхний тулбар и переключатель режимов (`src/components/StealthHUDTopToolbar.tsx`)

## Verification Plan

### Automated Verification
- Запуск `compile_applet` для валидации сборки Vite.
- Запуск `lint_applet` для проверки строгой типизации TypeScript (`tsc --noEmit`).

### Manual Verification
1. **Переключение темы**: Нажатие кнопки темы в правом верхнем углу переключает весь интерфейс между Dark и Light режимами без визуальных разрывов и артефактов.
2. **Контрастность и читаемость**: Проверить сайдбар, список маршрутов, тулбар и боевую ротацию в светлой теме — все надписи, активные маркеры и индикаторы должны быть четко различимы.
3. **Полноэкранный режим и масштабирование**: Проверить интерфейс на стандартном окне и в полноэкранном режиме — сайдбар и карточки пропорционально масштабируются, заполняя пространство гармонично без горизонтального скролла и искажений.
4. **Сохранение функционала**: Проверить запись маршрута, inline-загрузку слота, переключение режимов тулбара и редактирование комбо.
